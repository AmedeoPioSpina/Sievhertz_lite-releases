# Changelog

## v0.1.10 - 2026-11-15
- Songs start much faster: yt-dlp no longer unpacks itself on every song
- The fast loading path is used even when your YouTube account is connected
- Recently played songs start instantly, even after reopening the app
- The next 3 songs in the queue (and the first song of an album or playlist you open) are prepared in advance

## v0.1.9 - 2026-11-15
- cookies.txt guide: how to install the extension in Chrome, Edge, Firefox, Opera / Opera GX and Brave / Vivaldi

## v0.1.8 - 2026-11-15
- Fixed: in the player bar an empty music-note box appeared next to the song cover
- Clearer step-by-step guide for the cookies.txt file: which page to be on and which button to press

## v0.1.7 - 2026-11-15
- Connecting your YouTube account (cookies) now refreshes all your music right away: Home, liked songs, playlists and search
- Choosing the browser tests the connection immediately
- Fixed: right after opening the app your personal music sometimes didn't appear until you pressed F5

## v0.1.6 - 2026-11-15
- Security: from the cookies.txt file the app keeps only the YouTube cookies (in its own folder) and deletes the original file
- Security: cookies read from the browser are no longer left behind in a temporary file (the one left by older versions is deleted)
- New portable version (zip): unzip and run, no installation needed
- "Choose file…" button is now highlighted

## v0.1.5 - 2026-11-15
- cookies.txt file: choose it with "Choose file…" or drag it into the window

## v0.1.4 - 2026-11-15
- New opening animation (can be turned off in Settings)
- The window reopens with the size and position it had (maximized too); the first time it's bigger

## v0.1.3 - 2026-11-15
- First version published as a downloadable release
- Notification when a new version is out, with what's new

## v0.1.0 - 2026-11-15
- First version: search, Home, Spotify-style artist/album/playlist pages, favorites and local library,
  editable queue, YouTube account (cookies), English/Italian, automatic updates
